Вход в управление сайтом

Введите ключ доступа. Он сохранится в этом браузере.

Где взять ключ
  1. Войдите на github.com в аккаунт, у которого есть доступ к репозиторию сайта.
  2. Откройте создание ключа.
  3. Repository access → Only select repositories → ippo-yar.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Срок действия — год, нажмите Generate token и вставьте ключ сюда.

Выберите новость или создайте новую

Вставьте ссылку на пост ВКонтакте — текст и фотографии подтянутся сами, останется проверить и сохранить. Или напишите новость вручную и загрузите фото: они автоматически приведутся к единому размеру, обложка обрежется под формат сайта.
