# Сайт Ярославского регионального отделения ИППО

Статичный сайт без сборки: HTML + CSS + немного JS. Дизайн — по образцу иппо-пенза.рф, фон — с ippo.ru.

## Админка: /admin/
Адрес: **https://ippoyar.ru/admin/**. Вход по ключу GitHub (fine-grained token: доступ только к репозиторию ippo-yar, право Contents: Read and write). Ключ сохраняется в браузере.

- **Добавить по ссылке из ВКонтакте** — вставляете ссылку на пост, робот за 1–3 минуты забирает текст и фото, открывается редактор: проверяете заголовок, дату, текст и сохраняете.
- **Написать новость вручную** — заголовок, дата, текст, фото. Фото автоматически уменьшаются до 1600 px, обложка обрезается под 3:2 (1200×800).
- «Привести текст к стилю сайта» убирает эмодзи, хэштеги, лишние пробелы, ставит «ёлочки».
- Правки публикуются коммитом в `main`, Timeweb пересобирает сайт сам.

## Как добавить новость без админки
1. Откройте файл `data/vk-links.txt` на GitHub и нажмите карандаш (Edit).
2. Добавьте ссылку на пост ВКонтакте новой строкой, нажмите **Commit changes**.
3. Через 1–2 минуты робот (GitHub Actions) заберёт текст и фото поста и обновит `data/news.json`, сайт пересоберётся сам.

### Автоматически, без ссылок
Если добавить в репозиторий секрет `VK_TOKEN` (Settings → Secrets and variables → Actions) — сервисный ключ приложения ВКонтакте, — робот каждые 3 часа сам забирает последние 20 записей со стены группы, полный текст, дату и все фото. Без ключа ВК отдаёт только превью: первые ~100 символов и одно фото.

## Слайд-шоу
Фото берутся из папки Яндекс.Диска https://disk.yandex.ru/d/yNURkvisEZJ3XA. Чтобы обновить после замены фото в папке: Actions → «Обновление новостей и картинок» → Run workflow → галочка «Перекачать фото слайдера».

## Деплой
Timeweb App Platform → статичный сайт без сборки, корень репозитория, ветка `main`. Любой коммит в `main` публикуется автоматически.
